# 快速学习掌握一个领域的知识

一个基于学习科学的高效学习 Skill，让 AI Agent 帮你明确学习目标、找到知识缺口、安排有效练习，并用实际表现检验是否掌握。

**核心思想：用更少的无效投入，获得能够记住、理解并独立应用的领域知识。**

## 它能帮你做什么

- **建立学习路径**：把“我想学会某个领域”转化成可验证的任务，优先学习关键概念和必要前置知识。
- **诊断已有基础**：通过简短问题和实际任务定位薄弱点，跳过已经掌握的内容。
- **开展互动教学**：结合示例、独立练习和具体反馈，按表现调整难度与帮助程度。
- **安排间隔复习**：根据遗忘、错误和提示依赖调整复习，减少学完就忘。
- **验证真实掌握**：检查无提示表现、延迟保持和新情境应用，避免把“看懂答案”误判为学会。
- **延续学习进度**：记录目标、表现证据、常见误解和下一步任务，便于后续接着学。

## 学习流程

```text
明确目标 → 诊断基础 → 建立最短能力路径
                        ↓
           必要讲解与示例 → 独立练习
                        ↑       ↓
                   调整教学 ← 具体反馈
                                ↓
                    间隔复习 → 新情境验证
```

Agent 根据你的回答调整下一步。基础不足时提供示例，能独立完成时逐步减少帮助；反复出错时定位具体瓶颈，长期稳定通过时降低复习频率。

## 快速开始

将 [SKILL.md](./SKILL.md) 交给支持读取 Markdown 指令的 Agent，并发送：

```text
请按这份 SKILL.md 辅助我快速学习掌握【领域】。

我的目标：能独立完成【具体任务】。
已有基础：【已经学过或做过的内容】。
可用时间：每天【时长】，持续【天数或周数】。
期望保持：学完后【多久】仍然能够应用。

请先做简短诊断，再开始第一轮学习。
根据我的实际回答调整教学，安排间隔复习，并用新任务验证掌握情况。
```

如果使用的 Agent 支持 Skill 目录，将本仓库作为 `evidence-based-learning` 文件夹，放入该 Agent 规定的技能目录，按其方式加载。直接附上 `SKILL.md` 也可以使用这套流程；是否自动发现技能取决于具体 Agent。

### 示例：学习 SQL

```text
请按这份 SKILL.md 帮我学习 SQL。
我会使用 Excel，但没有数据库基础。
目标是在四周内独立完成业务数据的筛选、分组汇总和多表关联分析。
每天投入 30 分钟，希望一个月后仍能独立完成类似任务。
请先诊断基础，再给出第一道学习任务。
```

### 示例：理解一个陌生领域

```text
请按这份 SKILL.md 帮我建立对行为经济学的基础理解。
目标是能解释核心概念、识别生活中的案例，并说明理论的适用边界。
我每周有三次学习时间，每次 40 分钟。
请把概念解释、正反例辨析、主动回忆和复习结合起来。
```

## 方法依据

本 Skill 将以下研究支持的方法转化为 Agent 可以执行的教学规则：

| 方法 | 在学习中的作用 |
| --- | --- |
| 主动提取 | 尝试从记忆中回答或执行，检查缺口并练习提取 |
| 间隔练习 | 将再次学习分散到不同时间，支持长期保持 |
| 示例与逐步撤去帮助 | 让新手获得必要指导，随能力提升转向独立完成 |
| 自我解释 | 连接原理、步骤和适用条件 |
| 交错练习 | 在合适的材料中辨别概念或题型，练习选择方法 |
| 具体反馈 | 指出关键错误、依据以及下一次如何改进 |
| 延迟与迁移检查 | 检查是否记得住，以及是否能处理新的目标相关任务 |

其中，练习测试和分散练习有较广泛的研究支持；其他方法需要结合基础和任务类型使用。参见 [Dunlosky 等人的学习技术综述](https://pubmed.ncbi.nlm.nih.gov/26173288/)。完整的研究链接和适用条件见 [SKILL.md 的证据索引](./SKILL.md#证据索引)。

## 使用边界

“高效”指减少无效学习，并根据表现合理分配时间。不存在适合所有领域与所有人的固定速成配方。

这套 Skill 是研究方法与教学设计的组合，完整流程本身未经单独实验验证。示例题量、复习间隔和时间分配都是可调整的默认值，不是普适科学常数。Agent 应核对知识和答案；对于需要实际操作的技能，文字问答不能替代真实表现评估。
